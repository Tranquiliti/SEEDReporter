Version 2.0.0 (Update for Starsector 0.98.5a)

* Seeds saved in the JSON file now also include the current system date in addition to the game version
* Optimized "planetFilters" by not loading any unused planet filters
* The exception message is now printed if the SEED report failed to write the seed to file
* Commented out the "compressSaveGameData" setting in settings.json to avoid overriding the vanilla setting by default
* The AutoHotkey script loop will now automatically reload (to stop the script) if Starsector was closed during execution



Version 1.0.0

* Revamped SEED Report with multi-planet system search feature (implemented by brobinett)
  - Major changes to the "starSystemFilters" and "planetFilters" settings to allow searching for systems with multiple matching planets
  - Report no longer directly prints the "planetFilters" results; instead, "starSystemFilters" can now use planet filters to further filter out star systems
  - Added "starSystemFilterExecutionOrder" setting to avoid circular references with filter names
  - Consult the updated seedreporterSettings.json for further information on the new format!
* Replaced "hasEntityWithTags" with "hasEntityWithMemoryKeys"
  - Now also allows searching for entities with specified memory keys, IDs, names, etc.
  - Tags can still be searched by appending "$tag:" to the desired tag (e.g., "$tag:gate" instead of "gate")
* Fixed "maxHazardValue" option not properly taking the percentage value (fix by brobinett)
* "planetFilters" now supports searching for star types (e.g., black holes or neutron stars)
* Added error handling for SEED reports from "runSEEDReportOnGameStart" to avoid potential game crashes
* Added error handling when generating the defenders for the Tesseract search
* Star system filters with "saveShorthand" now also display their shorthand in the SEED report
* Added more star system filters to seedreporterSettings.json
  - Also includes filters for finding certain modded content; these are disabled by default
* Renamed default "hypershunt" filter to "coronalHypershunt"
* Moved "runSEEDReportOnGameStart" setting to settings.json (from seedreporterSettings.json)
  - Done to allow this setting to load, even when seedreporterSettings.json cannot be loaded due to errors
* Improved the AutoHotkey script
  - The script can now be toggled on/off using the backtick button
  - Starting the script also opens a GUI window as an activation reminder
  - Stopping the script now requires closing the GUI window (instead of pressing the Spacebar button)
